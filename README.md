# بوت تيليجرام لخدمات تصميم الباترونات

هذا المستودع يحتوي على كود بوت تيليجرام مصمم لشركة تقدم خدمات تصميم الباترونات للملابس، خدمات فنية في برنامج Gerber AccuMark، وبيع برامج مطورة خصيصاً.

**مميزات البوت:**

*   **استجابة متعددة اللغات:** يكتشف لغة العميل ويرد بنفس اللغة (العربية، الإنجليزية، وغيرها).
*   **التعامل مع أنواع الرسائل المختلفة:** يدعم الرسائل النصية، الصور، المستندات، والرسائل الصوتية.
*   **إعادة توجيه المحادثات للمالك:** يقوم بإعادة توجيه جميع رسائل العملاء وردود البوت إلى معرف دردشة المالك المحدد.
*   **استخدام OpenRouter API:** يستخدم نموذج DeepSeek عبر OpenRouter API لتوليد استجابات ذكية.
*   **نبرة احترافية وودودة:** يتواصل مع العملاء بأسلوب احترافي وودود.

## إعداد متغيرات البيئة

لضمان عمل البوت بشكل صحيح، يجب عليك تعيين متغيرات البيئة التالية:

*   `TELEGRAM_BOT_TOKEN`: توكن بوت تيليجرام الخاص بك.
*   `OWNER_CHAT_ID`: معرف دردشة تيليجرام الخاص بالمالك (لإعادة توجيه الرسائل).
*   `OPENROUTER_API_KEY`: مفتاح API الخاص بك من OpenRouter.

## خطوات النشر على Railway.app (أو أي خدمة استضافة أخرى)

لجعل البوت يعمل 24/7، يمكنك نشره على خدمة استضافة مثل Railway.app. اتبع الخطوات التالية:

1.  **إنشاء مستودع GitHub:**
    *   قم بإنشاء مستودع GitHub جديد (عام أو خاص) على حسابك: [https://github.com/new](https://github.com/new)
    *   قم بتحميل جميع الملفات الموجودة في هذا المشروع (`bot.py`, `requirements.txt`, `Procfile`, `.gitignore`, `README.md`) إلى المستودع الجديد.

2.  **النشر على Railway.app:**
    *   انتقل إلى [Railway.app](https://railway.app/) وقم بتسجيل الدخول.
    *   انقر على **"New Project"** (مشروع جديد).
    *   اختر **"Deploy from GitHub Repo"** (النشر من مستودع GitHub).
    *   قم بربط حسابك على GitHub (إذا لم تكن قد فعلت ذلك بالفعل) واختر المستودع الذي قمت بإنشائه للبوت.

3.  **تكوين المتغيرات البيئية (Environment Variables):**
    *   بعد اختيار المستودع، سيكتشف Railway تلقائيًا ملف `Procfile` ويبدأ في بناء المشروع.
    *   قبل أن يبدأ البناء، أو بعده، انتقل إلى إعدادات المشروع (Project Settings) أو إعدادات الخدمة (Service Settings) الخاصة بالبوت.
    *   أضف المتغيرات البيئية المذكورة أعلاه (`TELEGRAM_BOT_TOKEN`, `OWNER_CHAT_ID`, `OPENROUTER_API_KEY`) مع القيم الصحيحة.

4.  **بدء النشر:** بمجرد تكوين المتغيرات البيئية، سيبدأ Railway في نشر البوت تلقائيًا. يمكنك مراقبة سجلات النشر (Deployment Logs) للتأكد من عدم وجود أخطاء.

**ملاحظة:** تأكد من أن `Procfile` يحتوي على `worker: python bot.py` لتشغيل البوت كعملية خلفية مستمرة.
